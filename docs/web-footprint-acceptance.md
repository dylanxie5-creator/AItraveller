## 地图安全与失败降级

- 先在隔离 QA 数据库中使用显式假值验收错误凭据降级；随后由用户在“地图设置”页录入真实测试凭据。凭据值未写入源文件、命令行、文档、截图或提交记录。
- 错误凭据场景约 15 秒后显示“地图脚本加载超时”，同时保持 4 省、5 城市、6 次到访及完整列表可用；未出现未处理 Console 错误。
- `GET /api/map-settings` 只返回配置状态、固定高德来源和审图提示；`GET /api/map-session` 只返回 `provider/revision/key/serviceHost`，按高德浏览器协议包含 JS API Key，但不含安全密钥或密文。`serviceHost` 固定为同源 `/_AMapService`。
- 真实 SDK 请求到达同源代理时未携带 `jscode`；代理在服务端解密后追加安全密钥。代理只允许固定 district 路径和受限 JSON/JSONP 响应，JSONP 回调名及包装不匹配均拒绝。
- CSP 保持 `default-src 'self'`，只加入固定 `webapi.amap.com` 和 `*.amap.com` HTTPS 来源；为兼容高德 JS API 2.0 真实运行时，`script-src` 含必要的 `'unsafe-eval'`。安全代理仍是同源固定路径，用户设置不能扩展 CSP 主机。
