## 地图安全与失败降级

- 通过设置页仅在隔离 QA 数据库保存了显式假值 `QA-INVALID-AMAP-JS-KEY` 与 `QA-INVALID-AMAP-SECURITY`，用于错误凭据降级，不是真实凭据。
- 错误凭据场景约 15 秒后显示“地图脚本加载超时”，同时保持 4 省、5 城市、6 次到访及完整列表可用；未出现未处理 Console 错误。
- `GET /api/map-settings` 只返回配置状态、固定高德来源和审图提示；`GET /api/map-session` 按协议返回 JS API Key 与同源 `/_AMapService/<revision>`，两者都不含安全密钥或密文。
- CSP 保持 `default-src 'self'`，只加入固定 `webapi.amap.com` 和 `*.amap.com` HTTPS 来源；安全代理仍是同源路径，用户设置不能扩展 CSP 主机。
