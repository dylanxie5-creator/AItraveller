## 固定版式证据与限制

- 自动化测试锁定 `@page { size: A4 portrait; ... }`、打印时隐藏网站外壳与操作区、每趟行程前分页、条目防拆分、表头按页重复、长 URL 任意位置换行，以及至少 80 条明细不被客户端截断。
- 浏览器屏幕预览中，打印报告已经隐藏侧栏、顶栏和页脚；正常页面保留打印操作卡片。打印媒介规则会进一步隐藏该操作卡片。
- CSS 页码使用浏览器支持时可用的页计数器；不伪造总页数。不同浏览器版本、系统字体、纸张边距和打印机驱动可能产生不同的最终分页，正式留档前仍应在系统预览中人工快速检查。
- 网站不直接生成或保存 PDF，也无法知道用户最终是保存、打印还是取消，所以不会记录导出历史或宣称文件已保存。

已结束行程筛选、事务一致性、脱敏 API、单趟/总档案、三版攻略、完整花销与足迹、危险链接降级、静态快照、A4 打印规则和取消无写入均已通过自动化与内置浏览器验收。系统打印预览的驱动相关最终分页属于明确保留的人工检查项。
