# 智游足迹 · 本地网页版

独立于微信小程序的个人旅行手账。第一部分包括旅行概览、行程列表/详情、多城市三步编辑、预算和草稿恢复。暖色 UI 是可调整初稿。

## 启动与停止

本机已验证 Node.js **v25.9.0**。无第三方运行依赖，不需要 `npm install`。

在 PowerShell 中执行：

```powershell
cd 'C:\Users\X\Documents\ChatGPT\智游足迹网页版\.worktrees\web-foundation'
npm start
```

保持该终端运行，浏览器打开 <http://127.0.0.1:3210/>。用 **Ctrl+C** 停止服务；关闭浏览器不会停止服务。没有服务运行时，页面无法打开。

当前代码保留在 `codex/web-foundation` 的隔离工作区，尚未合并到项目主目录。如果以后合并，改为在主目录运行即可。

## 数据与边界

- 默认数据库为运行代码所在目录的 `runtime/travel.sqlite`；首次启动自动创建，停止/重启服务不删除行程或草稿。
- 数据只在本机，不同步微信、不上传云端；不要删除 `runtime`。首次从旧版 v1 升级到 v2 前，会自动生成并校验一次 SQLite 一致备份，保存到数据库旁 `backups/pre-ai-v1-<唯一编号>.sqlite`，包含已提交的 WAL 数据。这不是日常定时备份；界面备份/恢复功能仍留到后续阶段。
- 备份验证失败会停止升级；失败产物保留 `.partial` 后缀，不可当作完整备份使用。事务升级失败会回滚，保留旧记录和已验证备份。行程、活动草稿、已关闭草稿及保存回执均保留。
- Windows PowerShell 文件句柄保护同一数据库，换端口或等价路径也不能重复启动；正常停止或进程退出后自动释放。遗留 `.owner.lock` 文件本身不会阻止再次启动，不要靠删除该文件解除正在使用的数据库。
- 锁保护进程异常退出时，网站会停止接收请求、取消外部工作信号并关闭，命令行服务以失败状态退出；不支持时不会降级为无锁运行。此次只实现数据库与运行保护，尚无真实 AI 请求。
- 仅监听 `127.0.0.1`，不支持手机连接或跨设备使用。窄屏适配不代表手机可连接本机。
- 新建/编辑均有自动保存草稿；再次进入时可恢复。保存失败或版本冲突时保留输入，不自动覆盖另一标签页的修改。
- 提交结果不确定时，先点击“确认保存”重试核实；此时不能返回步骤或舍弃，以免丢失同一笔提交身份。确认成功后可在详情重新编辑。明确的字段校验失败则返回对应步骤修正。
- **删除行程无法通过界面撤销**，删除前会询问确认。本阶段尚无花销和足迹关联。
- 预算可不填；填写时需大于 0 且最多两位小数。城市日期必须在行程范围内，并按路线顺序排列，只允许相邻站点同日交接。
- AI、花销、足迹地图、登录、分享和互联网部署尚未实现；本阶段不需要 API Key。

如 3210 端口已占用，可临时指定其他端口：

```powershell
$env:TRAVEL_PORT = '3211'
npm start
```

仅在隔离验收时使用 `TRAVEL_DB_PATH` 指定测试库；正式使用建议保持默认，避免误以为数据丢失。遇到数据库损坏或未知版本会拒绝启动，不会自动覆盖旧文件。

更新前先停止旧版网站进程，再启动新代码；旧版进程与外部 SQLite 工具不参与本版本的独占协议，不支持同时操作。数据库硬链接别名会被拒绝；需要独立数据时使用普通副本。迁移备份需保留，恢复时应先停服并另存当前数据库，不要在运行中直接覆盖。

## 检查

### AI 设置底层进度

已实现五个平台独立的模型名/接口配置与版本保护，以及 Key 的保留、替换、明确删除。智谱搜索可复用智谱模型 Key，也可保存独立搜索 Key；切换复用模式不会自动删除独立 Key，需明确删除。

Key 使用 Windows DPAPI `CurrentUser` 保存为密文，不进入命令行参数、环境变量或日志；失败不改存量密文，也不降级为明文。一般绑定当前 Windows 用户/计算机，迁移账户或电脑可能需要重填。它不能防御已控制同一用户账号的恶意软件，也不能替代平台侧撤销凭据。[Microsoft 数据保护说明](https://learn.microsoft.com/en-us/dotnet/standard/security/how-to-use-data-protection)

公开设置只返回模型、地址、版本和配置状态，不返回 Key、片段或密文。“已配置”只表示已有密文，不代表 API 权限、余额或真实调用已验证。活动任务期间不能保存设置；加密等待期间版本或任务状态变化也会拒绝提交。

**设置页、AI HTTP 接口和真实平台请求尚未接入，当前无需输入 Key。** Windows 实测使用的均是假 Key，正式数据库没有保存测试设置。

### AI 安全传输与搜索底层进度

已实现完整 HTTPS 接口地址白名单，设置保存也共用此规则。地址必须匹配平台、主机与完整路径；不接受任意代理、编码路径、用户信息、查询串、片段或异常端口。白名单依据官方资料核对：[DeepSeek](https://api-docs.deepseek.com/)、[智谱](https://docs.bigmodel.cn/api-reference/工具-api/网络搜索)、[MiMo](https://mimo.mi.com/docs/zh-CN/quick-start/summary/first-api-call)、[Kimi](https://www.kimi.com/help/kimi-api/api-troubleshooting)、[千问地域与业务空间](https://help.aliyun.com/zh/model-studio/regions)。MiMo 暂限普通实时接口，不含批处理/Token Plan；千问保留官方旧版域名和已核实地域的单层业务空间域名，不自动切换地域或迁移 Key。

网络层检查全部 DNS 结果，只连接已核验的公网 IP，并用原域名校验 TLS 证书；混合私网结果也会拒绝。不跟随重定向，不自动重试，不访问搜索来源网页、图标或媒体。特殊用途/映射/转换地址保守拒绝，不支持依赖这些地址的自定义网络。[IANA IPv4 地址登记](https://www.iana.org/assignments/iana-ipv4-special-registry)、[IPv6 地址登记](https://www.iana.org/assignments/iana-ipv6-special-registry)

智谱独立搜索固定调用 `web_search`，搜索词最多 70 个 Unicode 字符；30 秒总超时包含 DNS 和响应读取，响应最多 1 MiB。无有效来源即失败；来源清洗、去重和限长，检索时间与文章发布日期分别保存。错误仅返回本地分类，不保留平台原始报错或密钥。模型调用最长 120 秒的传输底座已准备，但五平台模型适配属于下一项。

上述网络测试全部注入模拟 DNS/HTTPS，不产生真实或付费 API 请求；这不代表账户权限、余额、模型能力或平台可用性已实测。
