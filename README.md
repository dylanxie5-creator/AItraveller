# 智游足迹 · 本地网页版

独立于微信小程序的个人旅行手账。现包含旅行概览、行程列表/详情、多城市编辑、行程内花销与分类统计、中国足迹地图，以及使用自有 API Key 的 AI 检索规划、来源查看、手工编辑和一键创建正式行程。暖色 UI 是可调整初稿。

## 启动与停止

本机已验证 Node.js **v25.9.0**。无第三方运行依赖，不需要 `npm install`。

在 PowerShell 中执行：

```powershell
cd 'C:\Users\X\Documents\ChatGPT\智游足迹网页版'
npm start
```

保持该终端运行，浏览器打开 <http://127.0.0.1:3210/>。用 **Ctrl+C** 停止服务；关闭浏览器不会停止服务。没有服务运行时，页面无法打开。

## 数据与边界

- 默认数据库为运行代码所在目录的 `runtime/travel.sqlite`；首次启动自动创建，停止/重启服务不删除行程或草稿。
- 数据只在本机，不同步微信、不上传云端；不要删除 `runtime`。当前数据库版本为 v4。首次从旧版 v1、v2 或 v3 升级到 v4 前，会自动生成并校验一次 SQLite 一致备份，保存到数据库旁 `backups/pre-migration-v<旧版本>-<唯一编号>.sqlite`，包含已提交的 WAL 数据。旧版本会在同一次事务中依次补齐 AI、花销和足迹结构。
- 备份验证失败会停止升级；失败产物保留 `.partial` 后缀，不可当作完整备份使用。事务升级失败会回滚，保留旧记录和已验证备份。行程、活动草稿、已关闭草稿及保存回执均保留。
- Windows PowerShell 文件句柄保护同一数据库，换端口或等价路径也不能重复启动；正常停止或进程退出后自动释放。遗留 `.owner.lock` 文件本身不会阻止再次启动，不要靠删除该文件解除正在使用的数据库。
- 锁保护进程异常退出时，网站会停止接收请求、取消外部工作信号并关闭，命令行服务以失败状态退出；不支持时不会降级为无锁运行。
- 仅监听 `127.0.0.1`，不支持手机连接或跨设备使用。窄屏适配不代表手机可连接本机。
- 新建/编辑均有自动保存草稿；再次进入时可恢复。保存失败或版本冲突时保留输入，不自动覆盖另一标签页的修改。
- 提交结果不确定时，先点击“确认保存”重试核实；此时不能返回步骤或舍弃，以免丢失同一笔提交身份。确认成功后可在详情重新编辑。明确的字段校验失败则返回对应步骤修正。
- **删除行程无法通过界面撤销**，删除前会询问确认，并一并删除该行程的花销、自定义分类和操作回执。
- 预算可不填；填写时需大于 0 且最多两位小数。城市日期必须在行程范围内，并按路线顺序排列，只允许相邻站点同日交接。
- 花销只属于当前行程，可选默认或行程内自定义分类、路线城市或“整个行程”，并记录日期和备注。移出路线的城市仍以历史标记保留；正在使用的自定义分类不能删除。
- 登录、分享和互联网部署尚未实现。AI 功能需要用户自己的标准 API Key；不使用聊天会员或 Coding Plan 凭据替代标准 API 凭据。

如 3210 端口已占用，可临时指定其他端口：

```powershell
$env:TRAVEL_PORT = '3211'
npm start
```

仅在隔离验收时使用 `TRAVEL_DB_PATH` 指定测试库；正式使用建议保持默认，避免误以为数据丢失。遇到数据库损坏或未知版本会拒绝启动，不会自动覆盖旧文件。

更新前先停止旧版网站进程，再启动新代码；旧版进程与外部 SQLite 工具不参与本版本的独占协议，不支持同时操作。数据库硬链接别名会被拒绝；需要独立数据时使用普通副本。迁移备份需保留。恢复数据只能使用网站“数据安全”页，不要在服务运行或停止时手工把备份覆盖到正式数据库；内置恢复会校验文件、保存恢复前快照并在失败时回滚。

## 备份与恢复数据

1. 打开侧栏“数据安全”。网站启动时会检查自动备份：没有自动备份，或最近一次成功自动备份距今至少 24 小时，才创建一份；只自动保留最新 14 份自动备份。手动备份和每次恢复前生成的保护备份不会被这项轮换删除。
2. 在“创建手动备份”填写可选备注后创建。已验证备份保存在正式数据库同级的 `backups/data` 目录中；文件名是内部随机编号，请以页面中的日期、类型和备注辨认，不要自行改名或移动其中的文件。
3. 点击“下载”可把某份备份另存为 `.sqlite` 文件。需要带回本网站时，点击“导入备份”选择该文件；单个导入文件上限为 256 MiB，只接受本项目当前 v4 数据库，损坏、截断或其他应用的 SQLite 文件会被拒绝且不替换现有数据。
4. 点击“恢复”并确认后，网站先重新校验目标，再创建一份永久保留的“恢复前”备份，然后独占替换数据库并重新载入页面。恢复中的普通写入会被拒绝，失败时会回滚到原数据库。
5. 数据库里的模型和地图凭据仍是 Windows DPAPI `CurrentUser` 密文。备份适合同一台电脑、同一 Windows 用户恢复；换电脑或换 Windows 用户后，其他旅行数据可以存在，但这些凭据通常无法解密，需要重新填写。

下载文件是额外副本，不受网站的 14 份自动备份轮换影响，请自行保管。网站不提供云同步，也不会自动上传这些文件。

## 使用行程花销

1. 打开“我的行程”并进入一趟行程，在花销卡片中选择“查看全部”。
2. 点击“记录花销”，填写金额、分类、所属城市或“整个行程”、日期和可选备注；金额按人民币元输入，最多两位小数。
3. 花销页会显示累计金额、预算余额或超支状态，以及按分类、按城市汇总和全部记录。记录可编辑或在确认后删除。
4. “管理分类”只管理当前行程的自定义分类。重命名会同步更新历史记录的展示名称；分类仍被花销使用时会阻止删除。
5. 行程路线移除城市不会删除已有花销，相关记录会标记为“已移出路线”，仍可查看和编辑。

## 使用中国足迹地图

1. 已结束行程中的城市会自动形成足迹；结束日等于今天的行程要等到次日才点亮。重复到访同一城市会保留多次记录。
2. 打开“足迹地图”查看省份、城市和到访次数。即使没有配置地图 Key，省市列表、搜索、城市明细和管理功能仍可完整使用。
3. “补录足迹”支持只记年份、年月或完整日期；完整日期必须早于今天。手动记录可编辑或删除。
4. 自动足迹可修改备注，也可明确撤销；撤销后可在“管理足迹”恢复。删除正式行程后，已发生的足迹会转为独立历史记录，不会随行程消失。
5. 城市明细只汇总明确归属该城市的行程花销，不把“整个行程”的花销自动分摊到城市。

图形地图使用高德地图 JS API 2.0。进入“地图设置”填写自己的 Web 端 JS API Key 和安全密钥；建议在高德控制台限制可用域名和额度。JS API Key 按高德协议发送到浏览器，安全密钥仅由本机同源代理读取，不进入浏览器响应。两者均使用 Windows DPAPI `CurrentUser` 加密保存在本机数据库，换账户或电脑可能需要重新填写。

地图加载失败、断网或凭据无效时，页面会保留省市列表并显示本地错误。真实高德底图、省市交互、审图号和港澳台/南海诸岛显示已通过隔离本地环境验收，详见 [足迹地图验收记录](docs/web-footprint-acceptance.md)。

## 检查

### AI 设置底层进度

已实现五个平台独立的模型名/接口配置与版本保护，以及 Key 的保留、替换、明确删除。智谱搜索可复用智谱模型 Key，也可保存独立搜索 Key；切换复用模式不会自动删除独立 Key，需明确删除。

Key 使用 Windows DPAPI `CurrentUser` 保存为密文，不进入命令行参数、环境变量或日志；失败不改存量密文，也不降级为明文。一般绑定当前 Windows 用户/计算机，迁移账户或电脑可能需要重填。它不能防御已控制同一用户账号的恶意软件，也不能替代平台侧撤销凭据。[Microsoft 数据保护说明](https://learn.microsoft.com/en-us/dotnet/standard/security/how-to-use-data-protection)

公开设置只返回模型、地址、版本和配置状态，不返回 Key、片段或密文。“已配置”只表示已有密文，不代表 API 权限、余额或真实调用已验证。活动任务期间不能保存设置；加密等待期间版本或任务状态变化也会拒绝提交。

设置页和同源 AI HTTP 接口现已接入。Key 只应在本机设置页输入，保存成功或失败都会清空密码框；页面不显示、回填或提供复制已存 Key 的功能。Windows 浏览器验收只使用假 Key 和独立 QA 数据库，正式数据库没有保存测试设置。

### AI 安全传输与搜索底层进度

已实现完整 HTTPS 接口地址白名单，设置保存也共用此规则。地址必须匹配平台、主机与完整路径；不接受任意代理、编码路径、用户信息、查询串、片段或异常端口。白名单依据官方资料核对：[DeepSeek](https://api-docs.deepseek.com/)、[智谱](https://docs.bigmodel.cn/api-reference/工具-api/网络搜索)、[MiMo](https://mimo.mi.com/docs/zh-CN/quick-start/summary/first-api-call)、[Kimi](https://www.kimi.com/help/kimi-api/api-troubleshooting)、[千问地域与业务空间](https://help.aliyun.com/zh/model-studio/regions)。MiMo 暂限普通实时接口，不含批处理/Token Plan；千问保留官方旧版域名和已核实地域的单层业务空间域名，不自动切换地域或迁移 Key。

网络层检查全部 DNS 结果，只连接已核验的公网 IP，并用原域名校验 TLS 证书；混合私网结果也会拒绝。不跟随重定向，不自动重试，不访问搜索来源网页、图标或媒体。特殊用途/映射/转换地址保守拒绝，不支持依赖这些地址的自定义网络。[IANA IPv4 地址登记](https://www.iana.org/assignments/iana-ipv4-special-registry)、[IPv6 地址登记](https://www.iana.org/assignments/iana-ipv6-special-registry)

智谱独立搜索固定调用 `web_search`，搜索词最多 70 个 Unicode 字符；30 秒总超时包含 DNS 和响应读取，响应最多 1 MiB。无有效来源即失败；来源清洗、去重和限长，检索时间与文章发布日期分别保存。错误仅返回本地分类，不保留平台原始报错或密钥。

上述网络测试全部注入模拟 DNS/HTTPS，不产生真实或付费 API 请求；这不代表账户权限、余额、模型能力或平台可用性已实测。

### 五平台模型适配底层进度

已实现 DeepSeek、智谱、MiMo、Kimi、千问的独立文本请求适配，沿用安全传输；单次非流式请求、120 秒总超时，并按平台及已核实型号设置 8192 输出上限参数。保留手填模型名，不偷偷改用别的模型或猜测未知型号的思考开关。[各平台官方依据与适配契约](docs/ai-provider-contracts.md)

固定提示词只包含本次行程和限定来源，偏好/摘要置于独立 JSON 数据中。只接受正常完成的最终正文，不将思考过程或工具输出作为攻略；截断、非法 JSON、平台拒绝均安全失败，无自动修复或追加调用。用量只保留有界整数摘要，缺失不伪造费用。

生成页面、持久任务、攻略保存/编辑和转换已接入。每个城市最多一次顺序搜索（共 1–3 次），成功任务最多一次模型请求；调用预留先保存，不自动重试、修复或续写。任务页每 2 秒只做本机 GET 查询，刷新/重启可恢复已保存状态，活动任务在重启后标为中断而不会继续外部调用。

五平台均为官方契约核对与模拟协议通过，未验证任何实际账户或模型调用。详细浏览器证据、限制和真实联调状态见 [AI 页面验收记录](docs/web-ai-acceptance.md)。真实或可能付费的 smoke test 必须单独获得同意。

## 使用 AI 规划

1. 打开“模型设置”，只为准备使用的平台填写模型、官方接口和 API Key；联网检索可复用智谱模型 Key，或单独填写智谱搜索 Key。
2. 打开“AI 攻略”→“新建 AI 规划”，填写 1–3 个城市代码、日期、人数、预算和偏好。提交前页面会显示最多的外部调用次数。
3. 任务成功后查看逐日攻略和检索来源。模型输出不会作为 HTML 执行，非 HTTP(S) 来源不会生成链接。
4. 可手工修改日程；手工保存只写本机数据库，不调用 AI。点击“创建正式行程”前会确认，转换保存的是当时快照，之后两边互不覆盖。

本机无外联验收可运行：

```powershell
node scripts/start-ai-qa.mjs --port 3211 --db runtime/qa-ai.sqlite
```

该脚本只允许显式 QA 数据库，固定注入模拟搜索/模型，不会连接真实平台；不能用它证明真实 API 可用。
